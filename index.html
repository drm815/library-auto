📚 학교도서관 자동화 시스템

독서로 DLS의 도서목록을 매 시간 자동으로 Google Drive와 Google Sheets에 업데이트합니다. 크롬과 터미널 창 없이 백그라운드에서 조용히 실행됩니다.

🏫 DLS는 학교 내부망에서만 접근 가능하므로 학교 PC에서만 실행됩니다

service_account.json 파일이란?

반드시 보관해야 하는 구글 서비스 계정 키입니다

구글은 보안상 아무 프로그램이나 구글 드라이브와 시트에 접근하도록 허용하지 않습니다. 서비스 계정은 구글이 발급해준 전용 로봇 계정으로, 브라우저 인증 없이 자동화 프로그램이 24시간 구글 드라이브와 시트에 접근할 수 있게 해줍니다.
🚨 이 파일을 잃어버리면 Google Cloud Console에서 서비스 계정 키를 새로 발급받아야 합니다. 반드시 안전하게 보관하세요!
브라우저 인증창이 뜨지 않습니다 · 완전한 무인 자동화가 가능합니다
어느 학교로 이동해도 이 파일 하나만 있으면 구글 설정을 다시 할 필요 없습니다
파일 이름 변경 금지 · 반드시 service_account.json 그대로 유지
타인과 공유 금지 · 구글 드라이브/시트 접근 권한이 담긴 파일
3
설치 매뉴얼
처음 설치와 인사이동 시 설정 방법

STEP 0. 독서로 계정 준비

  • 1
    독서로 DLS에 인증서로 로그인
  • 2
    DLS 내에서 아이디/비밀번호 계정 새로 생성
  • 3
    생성한 계정에 소장자료관리 접근 권한 부여
⚠️ 인증서 로그인으로는 자동화가 작동하지 않습니다. 반드시 아이디/비밀번호 계정이 필요합니다!

STEP 1. setup.bat 실행

  • 1
    위에서 파일 3개를 모두 바탕화면에 다운로드
  • 2
    setup.bat 더블클릭
  • 3
    "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → [예] 클릭
  • 4
    Python 설치 창이 뜨면 맨 아래 [Add Python to PATH] 체크 후 [Install Now]
  • 5
    모든 완료 메시지 확인 후 아무 키나 눌러서 창 닫기
⚠️ Add Python to PATH 체크를 반드시 해야 합니다!
💡 setup.bat이 완료되면 run_hidden.vbs 파일이 자동 생성되고 작업 스케줄러도 등록됩니다. 이 파일 덕분에 1시간마다 자동 실행될 때 크롬과 터미널 창이 화면에 전혀 나타나지 않습니다!

STEP 2. 구글 서비스 계정 설정

  • 1
    console.cloud.google.com 접속 → 구글 계정 로그인
  • 2
    [새 프로젝트] 만들기 → 이름: 도서관자동화
  • 3
    [API 및 서비스] → [라이브러리] 에서 Google Drive API, Google Sheets API 각각 검색 후 [사용] 클릭
  • 4
    [IAM 및 관리자] → [서비스 계정] 클릭 → [+ 서비스 계정 만들기]
    서비스 계정 이름: library-auto → [만들기 및 계속] → [완료]
  • 5
    방금 만든 서비스 계정 클릭 → [키] 탭 → [키 추가] → [새 키 만들기] → JSON 선택 → [만들기]
    JSON 파일이 자동 다운로드됩니다. 파일명을 service_account.json 으로 변경 후 바탕화면에 저장
  • 6
    다운로드된 service_account.json 파일을 메모장으로 열어서 client_email 값을 복사해두세요.
    "client_email": "library-auto@도서관자동화.iam.gserviceaccount.com" 이 이메일 주소가 구글 드라이브·시트 공유에 필요합니다.
  • 7
    drive.google.com 접속 → [+ 새로 만들기] → [폴더] 클릭 → 이름: 도서관자동화 → [만들기]

    만든 폴더를 더블클릭해서 열기 → 주소창 URL 확인:
    https://drive.google.com/drive/folders/1ct-7HNMp612CUCRCT3r7MTkUVe2rHwly folders/ 뒤의 긴 문자열이 폴더ID입니다. 복사해서 메모해두세요!

    폴더에서 우클릭 → [공유] → 6번에서 복사한 서비스 계정 이메일 입력 → 권한: 편집자 → [보내기]
  • 8
    폴더 안에서 [+ 새로 만들기] → [Google 스프레드시트] 클릭 → 시트 제목을 도서목록 으로 변경

    주소창 URL 확인:
    https://docs.google.com/spreadsheets/d/1C2zISnzGyrxeOCHih5o-dW423ralnI1lvqGtBwwJWNk/edit /d/ 와 /edit 사이의 긴 문자열이 시트ID입니다. 복사해서 메모해두세요!

    시트 우측 상단 [공유] → 6번에서 복사한 서비스 계정 이메일 입력 → 권한: 편집자 → [보내기]
💡 서비스 계정에 드라이브 폴더와 스프레드시트 모두 편집자 권한으로 공유해야 합니다. 하나라도 빠지면 오류가 납니다!

STEP 3. 내 정보 입력

  • 1
    library_auto.py 우클릭 → [메모장으로 열기]
  • 2
    파일 맨 위 4줄 수정:
    아이디 = "독서로아이디"
    비밀번호 = "독서로비밀번호"
    FOLDER_ID = "구글드라이브폴더ID"
    SHEET_ID = "구글시트ID"
  • 3
    Ctrl+S 로 저장

STEP 4. 첫 실행

  • 1
    윈도우 검색창에 cmd 입력 후 실행
  • 2
    cd Desktop 입력 후 엔터
  • 3
    python library_auto.py 입력 후 엔터
✅ 서비스 계정 방식은 브라우저 인증창이 뜨지 않습니다! 바로 실행되어 🎉 모든 작업 완료! 메시지가 뜨면 성공입니다. 이제 1시간마다 백그라운드에서 자동 실행됩니다!
🟢service_account.json 파일만 있으면 5분이면 끝납니다! 구글 계정 설정은 다시 하지 않아도 됩니다.

새 PC에서 할 일 (4단계)

  • 1
    보관 중인 파일 4개를 새 PC 바탕화면에 복사
    service_account.json · library_auto.py · setup.bat · python-installer.exe
  • 2
    setup.bat 더블클릭 → Python 설치 + 라이브러리 설치 + 백그라운드 설정 + 스케줄러 등록 자동 완료
  • 3
    library_auto.py 메모장으로 열어서 독서로 아이디/비밀번호만 새 학교 계정으로 수정 → Ctrl+S 저장
  • 4
    cmd에서 python library_auto.py 실행 → 바로 완료! (브라우저 인증 없음)
💡FOLDER_ID, SHEET_ID는 그대로! 기존 구글 드라이브와 시트를 계속 사용합니다.

자주 발생하는 문제

  • Q
    setup.bat 실행이 안 돼요
    → 우클릭 후 [관리자 권한으로 실행]
  • Q
    Python 설치 후에도 오류가 나요
    → python-installer.exe 다시 실행 → [Modify] → [Add Python to PATH] 체크
  • Q
    구글 드라이브/시트 접근 오류가 나요
    → service_account.json의 client_email을 드라이브 폴더와 스프레드시트에 편집자 권한으로 공유했는지 확인
  • Q
    독서로 로그인이 안 돼요
    → 아이디/비밀번호 확인 · 소장자료관리 권한 확인 · 학교 방화벽 문의
  • Q
    작업 스케줄러에 도서관자동화가 없어요
    → setup.bat 을 관리자 권한으로 다시 실행
  • Q
    service_account.json 파일을 잃어버렸어요
    → console.cloud.google.com 접속 → [IAM 및 관리자] → [서비스 계정] → 해당 서비스 계정 클릭 → [키] 탭 → [키 추가] → [새 키 만들기] → JSON → 파일명 service_account.json 으로 변경
