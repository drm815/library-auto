시작 전 준비사항
설치 전 반드시 확인하세요
🔐
독서로 아이디/비밀번호 계정 필요
인증서 로그인 계정만 있다면 DLS 내에서 별도 아이디 계정을 직접 생성하세요. 인증서 로그인으로는 자동화가 작동하지 않습니다.
🔑
소장자료관리 접근 권한 확인
생성한 아이디 계정에 소장자료관리 접근 권한이 있어야 합니다. 권한이 없으면 도서목록 다운로드가 되지 않습니다.

setup.bat

🤖
library_auto.py
자동화 실행 스크립트 · 독서로 계정 정보만 입력하면 됩니다
재사용 ⬇ 다운로드
⚠️ oauth_credentials.json 파일은 구글 계정 설정 후 직접 발급받아야 합니다. 매뉴얼 STEP 2를 참고하세요.
3
설치 매뉴얼
처음 설치와 인사이동 시 설정 방법

STEP 1. setup.bat 실행

  • 1
    위에서 파일 3개를 모두 바탕화면에 다운로드
  • 2
    setup.bat 더블클릭
  • 3
    "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → [예] 클릭
  • 4
    Python 설치 창이 뜨면 맨 아래 [Add Python to PATH] 체크 후 [Install Now]
  • 5
    모든 완료 메시지 확인 후 아무 키나 눌러서 창 닫기
⚠️ Add Python to PATH 체크를 반드시 해야 합니다!

STEP 2. 구글 계정 설정

  • 1
    console.cloud.google.com 접속 → 구글 계정 로그인
  • 2
    [새 프로젝트] 만들기 → 이름: 도서관자동화
  • 3
    [API 및 서비스] → [라이브러리] 에서 Google Drive API, Google Sheets API 각각 검색 후 [사용] 클릭
  • 4
    [OAuth 동의 화면] → 외부 선택 → 앱 이름 도서관자동화 → 이메일 입력 → 저장 → 테스트 사용자에 본인 이메일 추가
  • 5
    [사용자 인증 정보] → [OAuth 클라이언트 ID] → 데스크톱 앱 → [JSON 다운로드] → 파일명을 oauth_credentials.json 으로 변경 후 바탕화면에 저장
  • 6
    drive.google.com → 새 폴더 도서관자동화 만들기 → 폴더 열고 주소창에서 폴더ID 복사
  • 7
    폴더 안에서 새 스프레드시트 도서목록 만들기 → 주소창에서 시트ID 복사

STEP 3. 내 정보 입력

  • 1
    library_auto.py 우클릭 → [메모장으로 열기]
  • 2
    파일 맨 위 4줄 수정:
    아이디 = "독서로아이디"
    비밀번호 = "독서로비밀번호"
    FOLDER_ID = "구글드라이브폴더ID"
    SHEET_ID = "구글시트ID"
  • 3
    Ctrl+S 로 저장

STEP 4. 첫 실행 및 구글 인증

  • 1
    윈도우 검색창에 cmd 입력 후 실행
  • 2
    cd Desktop 입력 후 엔터
  • 3
    python library_auto.py 입력 후 엔터
  • 4
    브라우저가 열리면 구글 로그인 → [고급] → [도서관자동화으로 이동] → [허용]
💡 구글 인증은 최초 1회만 합니다. 이후에는 자동으로 인증됩니다!
✅ 🎉 모든 작업 완료! 메시지가 뜨면 성공입니다. 이제 1시간마다 자동으로 실행됩니다!
🟢 json 파일만 있으면 5분이면 끝납니다! 구글 계정 설정은 다시 하지 않아도 됩니다.

새 PC에서 할 일 (4단계)

  • 1
    이 페이지에서 파일 3개 다운로드 + 보관 중인 oauth_credentials.json 을 바탕화면에 저장
  • 2
    setup.bat 더블클릭 → Python 설치 + 라이브러리 설치 + 스케줄러 등록 자동 완료
  • 3
    library_auto.py 메모장으로 열어서 독서로 아이디/비밀번호만 새 학교 계정으로 수정 → Ctrl+S 저장
  • 4
    cmd에서 python library_auto.py 실행 → 구글 인증 한번만
💡 FOLDER_ID, SHEET_ID는 그대로! 기존 구글 드라이브와 시트를 계속 사용합니다.

자주 발생하는 문제

  • Q
    setup.bat 실행이 안 돼요
    → 우클릭 후 [관리자 권한으로 실행]
  • Q
    Python 설치 후에도 오류가 나요
    → python-installer.exe 다시 실행 → [Modify] → [Add Python to PATH] 체크
  • Q
    구글 인증이 계속 실패해요
    → 바탕화면의 token.json 삭제 후 다시 실행
  • Q
    독서로 로그인이 안 돼요
    → 아이디/비밀번호 확인, 학교 방화벽 문의
  • Q
    작업 스케줄러에 도서관자동화가 없어요
    → setup.bat 을 관리자 권한으로 다시 실행
